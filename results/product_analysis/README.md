# Product Analytics Outputs

Generated by `scripts/analyze_marketshield.py` from the committed prequential prediction cache and historical regression backtest.

## Outputs

| Artifact | Description |
|---|---|
| `classification_performance_curves.png` | ROC and precision-recall curves for existing core and expanded model probabilities across validation and retrospective replay windows |
| `validation_threshold_sensitivity.png` | Precision, recall and F1 across thresholds calculated on the validation window only |
| `retrospective_model_comparison.png` | Descriptive comparison of fixed supplementary models on the previously examined later replay window |
| `retrospective_model_comparison.csv` | Metrics and confusion counts for the retrospective model comparison |
| `primary_model_metrics.csv` | Core, expanded and momentum-baseline metrics for validation and retrospective replay |
| `expanding_history_sensitivity.png` / `.csv` | Training-volume sensitivity evaluated on the final six months of the internal 2021 validation period |
| `regularization_sensitivity.png` / `.csv` | Logistic-regression regularization comparison evaluated on the internal chronological validation window |
| `feature_importance.png` / `.csv` | Random Forest feature importance fitted using pre-replay target periods |
| `decision_tree_rules.txt` | Interpretable tree fitted on pre-replay data |
| `pca_projection.png` / `pca_loadings.csv` | PCA fit only on pre-replay predictors; target labels are used for plot coloring only, never as PCA inputs |
| `anomaly_detection.png` / `replay_anomaly_scores.csv` / `anomaly_summary_by_market.csv` | Isolation Forest fitted on pre-replay predictors and descriptive later-replay summaries |
| `historical_forecast_error.png` | Existing expanding-window regression MAE/WAPE by year |
| `analysis_run_summary.json` | Machine-readable methodology and run metadata |
| `OUTPUT_INDEX.csv` | Artifact sizes for handoff verification |

## Methodological safeguards

- The target is `shock_gt5`; it is never included in the fitted feature matrix.
- `next_pct_change` and `next_date` are never model features.
- New comparison models use only `previous_month_change`, calendar features and market ID known at the forecast origin.
- Regularization and learning-history sensitivity are assessed on a chronological internal validation window. The later replay does not choose hyperparameters.
- The later replay period has been examined previously and is **not** an untouched independent holdout. The figures are retrospective analyses, not evidence of operational readiness.

## Reproduction

From the repository root:

```powershell
python scripts/analyze_marketshield.py
```
