# يمن MarketShield AI — حزمة التسليم البحثية الكاملة

**نوع المشروع:** حزمة بحث وتحقق من النماذج تضم دفاتر Jupyter وبيانات المصدر المتاحة وملفات النتائج والتقارير.  
**الحالة:** نموذج بحثي أولي فقط، وليس نظام إنذار غذائي تشغيليًا أو خدمة إنتاجية جاهزة للنشر.

## محتويات الحزمة

1. `Yemen_MarketShield_Model_Validation.ipynb`: التجربة الرئيسية باستخدام بيانات أسعار الغذاء التاريخية من World Bank، مع اختبار زمني متدرج شهريًا ومقارنة نموذج LightGBM الأساسي بالنموذج الموسّع.
2. `Yemen_MarketShield_WFP_External_Validation.ipynb`: تجربة منفصلة باستخدام بيانات أسعار القمح الفعلية التي وصلت عبر HDX HAPI التابعة لـ WFP، وتعمل محليًا في VS Code/Jupyter أو في Google Colab.
3. مجلد `docs/`: ملخص المشروع، والتقرير التفصيلي للتجربة الرئيسية، وتقرير تجربة WFP، وخطة التحقق المستقل.
4. ملفات CSV للتنبؤات والملخصات ومقارنة العتبات ونتائج الانحدار.
5. مجلد `results/`: نواتج تجربة WFP، ومنها الأزواج المطابقة والمقاييس والتنبؤات المستقبلية.
6. مجلد `scripts/`: سكربت لفحص سلامة الحزمة وملفات النتائج.
7. ملفات ZIP المؤرخة لبيانات World Bank ولقطة استجابة HAPI كانت ضمن حزمة التسليم المحلية الأصلية، لكنها غير مرفوعة إلى مستودع GitHub العام حاليًا؛ أُبقيت خارج المستودع إلى حين مراجعة شروط إعادة الاستخدام.

## التشغيل في Windows وVS Code

افتح هذا المجلد في VS Code، ثم نفّذ في Terminal:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python scripts/validate_submission.py
```

بعد ذلك افتح كل دفتر، واختر بيئة Python نفسها، وشغّل الخلايا من البداية إلى النهاية.

- **ملاحظة حول مستودع GitHub العام:** ملفات المصدر الخام غير مرفوعة عمدًا. لإعادة تشغيل الدفتر الرئيسي، نزّل إصدارات 2026-03-24 من السجلات الرسمية: أسعار الغذاء https://microdata.worldbank.org/catalog/4508، وأسعار الصرف https://microdata.worldbank.org/catalog/6159، والطاقة https://microdata.worldbank.org/catalog/6133، ثم ضع ملفات ZIP الثلاثة بجانب الدفتر. المتغير `RETRAIN_MODELS = False` يعيد استخدام ملفات التنبؤ بعد فحص تطابقها؛ و`True` يعيد التدريب.
- دفتر WFP يحتاج أيضًا إلى ملف استجابة JSON محفوظ من HDX HAPI لليمن، والقمح (commodity code 84)، والأسعار الفعلية بالتجزئة، والعملة YER، والوحدة KG حتى أكتوبر 2026. ملف `Yemen_MarketShield_WFP_Validation_Outputs.zip` يحتوي على النتائج المشتقة فقط، ولا يحتوي على ملف HAPI الخام. دليل الاستخدام: https://hdx-hapi.readthedocs.io/en/latest/data_usage_guides/food_security_nutrition_and_poverty/. في Colab ارفع ملف HAPI وملف World Bank الغذائي عند الطلب.

## أهم النتائج

- تجربة World Bank: عدد التنبؤات 2,088؛ 864 سجلًا للتحقق و1,224 سجلًا للفترة اللاحقة. أداء النموذج تراجع على الفترة اللاحقة، وحوالي 77% من تنبيهاته كانت إنذارات كاذبة.
- تجربة WFP: 62 سجلًا في الاختبار اللاحق من 11 سوقًا بين أبريل وسبتمبر 2026. حقق خط أساس السعر السابق MAE قدره نحو 20 ريالًا لكل كغ وWAPE قدره 2.41%. أما مصنف ارتفاع السعر بأكثر من 5% فأنتج 50 إنذارًا كاذبًا من أصل 55 تنبيهًا، وكان F1 نحو 0.164.

## حدود يجب ذكرها للدكتور

- الفترة اللاحقة في تجربة World Bank اطلع عليها الفريق سابقًا أثناء التطوير، لذلك ليست اختبارًا مستقلًا غير ممسوس.
- المقارنة التاريخية بين WFP وWorld Bank تقريبية من حيث ربط الفترات، وقد تتداخل المصادر في أصول بياناتها؛ لذا لا نصفها بأنها تحقق مستقل بالكامل.
- فترة اختبار WFP المستقبلية قد تمت مراجعتها بالفعل، فلا يجوز اعتبارها غير ممسوسة لجولة لاحقة من ضبط النماذج.
- النموذج لم يثبت جاهزيته للاستخدام الإنساني أو المالي أو التشغيلي. هذه الحزمة لا تضم موقعًا مستضافًا أو API حيًا أو نظام تنبيهات إنتاجيًا.
- ملفات البيانات الخام كانت ضمن الحزمة المحلية للتسليم، لكنها غير مرفوعة إلى GitHub العام حتى تُراجع شروط إعادة استخدامها. اجتياز سكربت الفحص على المستودع العام لا يعني أن دفاتر التحليل ستُعاد تشغيلها دون تنزيل ملفات المصدر.
