# Yemen MarketShield AI

## مراقبة أسعار القمح وتحليل المخاطر في اليمن

**حالة المنتج:** نموذج أولي للتحليل ودعم القرار. يوفر الإصدار الحالي معالجة بيانات قابلة للتكرار، وتقييمًا زمنيًا للتنبؤات، ومقارنة بخطوط أساس، وتحليلًا للعتبات ومؤشرات على مستوى الأسواق. لا يتضمن الإصدار خدمة تنبيهات حية، ولم تثبت صلاحيته لاتخاذ قرارات إنسانية أو شرائية أو مالية أو قرارات تحذير عامة.

## نظرة عامة على المنتج

يستكشف Yemen MarketShield AI إمكانية الاستفادة من بيانات الأسعار التاريخية والإشارات الزمنية لتحديد الأشهر التي قد تشهد ارتفاعًا ملحوظًا في تقديرات أسعار القمح المسجلة. يجمع المشروع فحوصات جودة البيانات، والتقييم الزمني، ومقارنة النماذج بخطوط أساس، وتحليل العتبات، وملخصات الأداء حسب السوق، واستكشاف القيم الشاذة ضمن مستودع واحد قابل للمراجعة.

يُعرّف الهدف الأساسي بأنه ارتفاع تقدير الإغلاق الشهري `c_wheat` من البنك الدولي بأكثر من 5% في الشهر المتتالي التالي. هذا تعريف إحصائي خاص بالمشروع، وليس مؤشرًا رسميًا لانعدام الأمن الغذائي أو الأزمات الغذائية أو الاحتياج الإنساني.

## المنهجية والأدلة الحالية

### التقييم الشهري ببيانات البنك الدولي

يحتوي ملف التنبؤات الحالي على 2,088 سجلًا عبر 24 سوقًا محليًا: 864 سجلًا في فترة التحقق 2019–2021 و1,224 سجلًا في فترة الإعادة اللاحقة التي تبدأ في 2022. اختيرت العتبات من فترة التحقق وثُبّتت أثناء تقييم الفترة اللاحقة.

| النموذج / الفترة | العتبة | ROC-AUC | Precision | Recall | F1 | التنبيهات | الإنذارات الكاذبة |
|---|---:|---:|---:|---:|---:|---:|---:|
| LightGBM الأساسي — التحقق | 0.475 | 0.749 | 0.435 | 0.670 | 0.528 | 285 | 161 |
| LightGBM الأساسي — الإعادة اللاحقة | 0.475 | 0.684 | 0.224 | 0.555 | 0.319 | 384 | 298 |
| النموذج الموسع — التحقق | 0.500 | 0.747 | 0.459 | 0.611 | 0.524 | 246 | 133 |
| النموذج الموسع — الإعادة اللاحقة | 0.500 | 0.680 | 0.223 | 0.510 | 0.310 | 355 | 276 |

تُظهر الفترة اللاحقة عبئًا مرتفعًا من الإنذارات الكاذبة: نحو 77.6% للنموذج الأساسي و77.7% للنموذج الموسع. ولم تؤدِ إضافة مؤشرات جودة البيانات إلى تحسين F1 في هذه الفترة وفق النتائج الحالية.

### تجربة WFP/HDX HAPI

تتضمن التجربة المنفصلة 62 سجلًا في الفترة اللاحقة عبر 11 سوقًا بين أبريل وسبتمبر 2026. حقق خط أساس السعر السابق في الانحدار `MAE` بنحو 20 ريالًا يمنيًا لكل كغ و`WAPE` بنحو 2.41%. أما مصنف الارتفاع بأكثر من 5% فأصدر 55 تنبيهًا، منها 50 إنذارًا كاذبًا، وبلغ `F1` نحو 0.164. لا تدعم هذه النتائج استخدام النموذج لإصدار تنبيهات تشغيلية.

## التشغيل وإعادة الإنتاج

### إعداد البيئة في Windows وVS Code

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install -r requirements-validation.txt
python .\scripts\validate_submission.py
python .\scripts\analyze_marketshield.py
```

افتح الدفاتر في VS Code أو Jupyter واختر بيئة Python نفسها، ثم نفّذ الخلايا من البداية إلى النهاية.

### ملفات المصدر

لا تُرفع لقطات بيانات المصدر الخام إلى المستودع العام حاليًا إلى حين تأكيد شروط إعادة توزيعها. لإعادة تشغيل الدفاتر الرئيسية، احصل على إصدار البنك الدولي المؤرخ `2026-03-24` من الروابط الرسمية وضع أرشيفات ZIP الثلاثة بجانب الدفاتر:

- أسعار الغذاء: https://microdata.worldbank.org/catalog/4508
- أسعار الصرف: https://microdata.worldbank.org/catalog/6159
- أسعار الطاقة: https://microdata.worldbank.org/catalog/6133

يحتاج دفتر WFP/HAPI أيضًا إلى ملف استجابة محفوظ لأسعار القمح الفعلية بالتجزئة في اليمن، بالريال اليمني/كغ. راجع دليل الاستخدام: https://hdx-hapi.readthedocs.io/en/latest/data_usage_guides/food_security_nutrition_and_poverty/. لا تضف بيانات اعتماد API أو معرفات تطبيق خاصة أو أسرارًا إلى المستودع. ملفات `results/` المرفوعة هي نتائج مشتقة؛ ولا يحتوي أرشيف النتائج على مدخل HAPI الخام.

يستخدم سكربت التحليلات التكميلية خصائص معروفة عند نقطة التنبؤ فقط (`previous_month_change` وميزات التقويم ومعرف السوق)، ويستبعد `next_pct_change` و`shock_gt5` من مصفوفة الخصائص. تُقيّم حساسية حجم السجل وقوة التنظيم على نافذة تحقق زمنية داخلية؛ ولا تُستخدم الفترة اللاحقة لاختيار الإعدادات الفائقة.

## القيود والاستخدام المقصود

1. سبق فحص فترة الإعادة اللاحقة لبيانات البنك الدولي أثناء التطوير؛ لذلك ليست مجموعة اختبار مستقلة لم تُستخدم سابقًا.
2. تحتوي سلسلة البنك الدولي على تقديرات إغلاق شهرية قابلة للمراجعة، ولا يثبت الملف التاريخي المجمد أن كل قيمة كانت متاحة بالشكل ذاته عند كل نقطة تنبؤ ماضية.
3. التوافق التاريخي بين World Bank وHAPI وصفي؛ فقد تتشارك المصادر في منشأ البيانات، كما قد تختلف الفترات أو تعريفات المنتجات.
4. سبق تحليل نافذة WFP اللاحقة، ولا يجوز اعتبارها اختبارًا نهائيًا غير مستخدم عند مواصلة ضبط النماذج.
5. يشير معدل الإنذارات الكاذبة المرتفع إلى أن النماذج الحالية غير مناسبة للتنبيهات التشغيلية دون اختبار مستقل إضافي ومعايرة وتحليل تكلفة الإنذار وتجربة صامتة.
6. المستودع الحالي نموذج أولي للتحليل ودعم القرار، ولا يتضمن لوحة معلومات مستضافة أو API حيًا أو خدمة إرسال تنبيهات أو نظام مراقبة إنتاجيًا.
